# Changelog

## Unreleased

- Add the Dupire core from DAL 2026.11.1: `DupireRiskInputs_` and `DupireCalibration_New` calibrating the `DupireCentral1e-4FixedBaseBand/v1` stencil onto the densified inclusion grid (snapshot values bit-exact on every probed fixture across Black-Scholes, Merton, callable and bumped-quote bases), `DupireModelData_New` pricing through the standard engine with the native 21-input risk axis, the `DupireScriptRiskRequest_`/`DupireQuoteBinding_`/`CalibrationRiskRequest_` planner chain (`DupireScriptRiskPlan_New`/`DupireScriptRiskResult_New`) with method strings `NativeAADThenNativeAADCalibrationVJP`, `NativeAADWithRetrainedPolicySecantThenNativeAADCalibrationVJP` and `ExpiredThenNativeAADCalibrationVJP`, the pullback names (`DupireParameterAdjoints_FromRisk`, `DupireQuoteRisk_New` with unit `decimal-vol`, `DupireScriptQuoteRisk_New` with additive direct adjoints), and quote-space curvature (`BumpOverAADRequest_` directions per flattened quote spread, `DupireScriptCurvaturePlan_New`/`DupireScriptCurvatureResult_New`, method `BumpOverRecalibratedNativeDupireMonteCarloAAD`). The pullback is an analytic VJP of the calibration standing in for native's AAD replay: derived tolerances, not guesses — ~2e-9 relative on quote adjoints (the roundoff floor native's own replay bounds acknowledge for the 1e-4 stencil) and rtol 1e-6/atol 1e-5 on curvature hessians (the VJP floor amplified by 1/(2·step); native's own halved-step hessians differ by ~1.4 absolute, so parity holds only at equal steps). Known divergences: (1) the callable base takes `IVS_(implied_vol=callable)` instead of a C++ trampoline subclass (subclassing still works); (2) nested numeric rows are accepted where native demands `DoubleMatrix_` (quote spreads, adjoint seeds, bump directions), so matrix-level type errors surface at entry level instead; (3) native accepts any currency string end-to-end while our hybrid reuses the LocalVol currency gate (pinned test); (4) request-level external `direct=` adjoints are rejected with native's binding message until the rate-curve calibration layer they share exists, and `CalibrationPullback_`/`PullbackCalibration`/`CalibrationRiskPlan_New`/`CalibrationRiskResult_New` stay unmirrored for the same reason; (5) enum value-reprs are omitted from input-context error text.
- Add the portfolio risk API from DAL 2026.11.1: `ScriptPortfolio_New` (per-trade models with identity-deduplicated `model_owners`), `PortfolioMonteCarlo_ValueWithJacobianRisk` and `PortfolioMonteCarlo_ValueWithWeightedRisk` with the `model:<owner>:parameter:<n>` / `trade:<position>:constant:<n>` input axis, `trade:<position>:payoff` output axis, block-diagonal cross-trade Jacobians, per-(owner, timeline) execution groups and native-matching guards, request metadata validation and `report_factors` scaling. The six `ScriptInstrument_New` factories and `ScriptInstrumentDefinition_*` are not mirrored: they consume native `YCInstrument_` handles that Python cannot construct (the `GSRMonteCarloPrice_` precedent).
- Document the XCCY and rate quote-risk domains as deferred after systematic reachability probes (`docs/xccy-reachability.md`, `docs/rate-quote-risk-reachability.md`): the XCCY valuation surface is gated behind a native convention check unsatisfiable from Python, and quote-risk is entirely downstream of curve calibration, which stays out of scope. The IR instrument factories and `ScriptInstrumentDefinition_*` stay unmirrored for the same reason (native handles unreachable from Python).
- Add the request-driven risk API from DAL 2026.11.1: `MonteCarlo_ValueWithRisk`, `MonteCarlo_ValueWithJacobianRisk` and `MonteCarlo_ValueWithWeightedRisk` with `RiskRequest_`-style coordinate selection over the model-parameter and script-constant axes, `Product_Get_RiskOutputs` slots derived from the scalar variable table, native-matching provenance and legacy `PV`/`d_*` values, and pre-binding EXERCISE/fully-expired guards for the Jacobian and weighted estimators.
- Add an exact `PseudoRSG` (MRG32k3a) compatibility stream with native antithetic uniforms and precise normals (`PseudoRSG_New`, `PseudoRSG_Get_Uniform`, `PseudoRSG_Get_Normal`).
- Wire `normal_precision='Precise'` to the precise Sobol inversion (pricing, LSMC training and RQMC replays share one composition rule); make `lsmc_training_memory_mb` force the checkpointed training scan with unchanged numbers.
- Add the `BlackScholesMonteCarlo` plan API (`Plan_New`, `Get_Risk`, `Get_Curvature`) with script constants joining the parameter labels, `first_path` as a Sobol point-ID offset, curvature via bump revaluation of the AAD gradient, and `SegmentedMonteCarloSettings_` execution settings. `GSRMonteCarloPrice_` stays unmirrored: native Python never constructs it (calibration-internal). Known gaps documented in the code: pseudo-RSG `first_path` has no effect (streams are not bit-compatible), `segment_steps`/budget fields are validate-and-echo, and native AAD-tape telemetry is reported as `None`. Fully expired risk valuations now label their method `Expired` and retrained-policy exercises `NativeAADWithRetrainedPolicySecant`, matching native.
- Upgrade to dal-python 2026.11.1 and JAX 0.12, and track uv.lock in git so every workflow resolves reproducible dependency sets instead of silently following new PyPI releases.
- Match the 2026.11.1 DAL diagnostics: report `normal_precision`, `lsmc_checkpoint_block_events` and `lsmc_training_memory_mb` (with native validation rules) and mirror `compiled` in the simulation settings explanation.
- Parse variadic `MIN`/`MAX` as left-folded binary chains (`MIN(a, b, c)` becomes `min(min(a, b), c)`), matching the 2026.11.1 DAL AST shape in `Product_Describe` dumps.
- Compare LSMC training coefficients only for full-rank fits: rank-deficient regressions are unique modulo the null space, so the oracle test pins degrees, ranks and values there.
- Run the native-oracle CI and GPU jobs against the pinned dal-python wheel from the lockfile; the wheel now ships the full oracle API, and building the C++ source on the runner drifted numerically with the Ubuntu 26.04 toolchain.
- Freeze engine configuration and snapshot sequence inputs; expose explicit valuation contexts and owned sessions while deprecating legacy global setters.
- Return immutable LSMC training/valuation results, move caches outside transformed kernels, and add per-engine cache clearing.
- Batch GSR, GSRSLV and Hybrid coefficient preparation; use a reverse device-training scan and CPU ordered Welford scan while retaining measured GPU fallbacks.
- Standardize Python with Ruff and CI checks; consolidate feature explanations, settings, numerical contracts and migration guidance in user documentation.

## 0.1.0a1

- Pure Python/JAX Monte Carlo valuation with CPU and CUDA extras, float64 defaults, blocked execution and four parallel strategies.
- DAL-compatible scalar/vector scripts, schedules, historical fixings, delayed payments, fuzzy risks and JAX differentiation.
- Black–Scholes, correlated equities, local volatility, single/multi-factor GSR, GSRSLV and named-factor domestic hybrids.
- Three-phase LSMC with normalized regression, rank guards, validation-based degree selection, independent randomized Sobol replicas and frozen/retrained-policy risks.
- Preparation/simulation diagnostics, sixteen executable DAL comparison examples and CPU/GPU validation.
