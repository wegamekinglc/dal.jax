# P5：完整脚本能力与多资产

P5 实现向量求值、FIX/历史定盘准备、延迟支付、相关性 Black–Scholes 和局部波动率。普通 Python 示例 09–12 在同一 Sobol 路径上逐项校验价格与全部模型/脚本敏感度，并输出编译时间和同步运行时间。

## 脚本状态与错误

`ScriptState` 保存标量数组、定容向量数组、整数长度和每个向量的错误标志。`APPEND` 和下标写入使用掩码，扩展位置之间补零；每条路径从同一个历史种子开始。SUM 的空向量值为零；AVERAGE/MIN/MAX 的空向量和无效读取会报具名错误。MIN/MAX 的并列最值沿用 DAL 的首个元素导数。

fuzzy IF 的两个分支从同一入口状态执行。过渡区使用较长长度，较短分支补零后混合；degree 到端点时保留所选分支的实际长度。未选中分支的错误标志不生效，尾块填充路径的错误不进入归约。

`engine.value()` 在一次价格/梯度计算后检查错误标志，抛出 `VectorIndexOutOfRange` 或 `EmptyVectorReduction`。原生 JAX 组合使用 `checked_pricer(n_paths)`，返回 `(prices, error_rates)`；普通 `pricer` 对存在错误的结果返回 NaN。设备端错误消息包含错误码和向量名，暂不定位具体失败路径或源码行；主机历史回放保留源码位置。

延迟支付的事件模板移除已绑定的付款日期、保留 `discount_id`，让不同付款日期的相同支付事件也能分组。长事件组的 scan body 使用 checkpoint，与块级 checkpoint 受同一个设置控制。GPU 块估算增加脚本状态容量和错误输出，避免只按模拟时间轴估计向量产品。

## FIX、快照和付款

```python
import dal_jax as dj
from dal_jax.api import Product_New
from dal_jax.dates import Date

today = Date.ymd(2022, 9, 15)
model = dj.BlackScholes(spot=100., vol=.15, rate=.05, div=.03)
fixings = dj.FixingSnapshot({"EQ[A]": {today: 97.}})
valuation = dj.ValuationSettings(evaluation_date=today, fixings=fixings,
                                today_fixing_policy="RequireHistorical")
product = Product_New([today], ["pay PAYS FIX(EQ[A])"])
prepared = dj.prepare(product, model=model, valuation=valuation)
result = dj.MonteCarloEngine(prepared.path_product(), model,
                            dj.MonteCarloSettings(enable_aad=True)).value(16)
# PV=97, d_spot=0
```

快照复制输入并规范化指数名。`Date` 对应午夜；Python datetime 保留微秒级精确时间。只匹配请求的时间，不拿当天其他时间的报价替代。FX 必须正且有限；支持反向报价求倒数，双向报价须互相一致。显式快照优先于进程内全局快照；准备时只捕获一次。

当日默认 `Model` 使用模型，不读取快照；`RequireHistorical` 使用当日历史报价。过去的 FIX 缺失时报 `MissingFixing`，不会退回模型。所有分支在常量折叠前校验，包含未选中分支中的非法观察。完全到期产品沿用 DAL 的历史 FIX 跳过规则。历史 SPOT 仍接受 `historical_spots`。

观察日期与事件日期可以不同。准备结果把两者合并成模拟时间轴，按指数/日期去重观察，再把事件重映射到样本。每个事件的延迟付款请求对应贴现槽位，`amount * discount(payment) / numeraire(event)` 保留支付日期的 rate 风险。过去事件中尚未结算的延迟付款报 `UnsettledDelayedPayment`。

普通 BS 支持一个未来 plain-EQ 指数，相关性 BS 支持已声明的多个指数。历史 EQ/FX/Libor 可由快照提供；历史 IR-DF 和未来 FX/rate 输出不在这些模型的能力内，报明确错误。SPOT 与 FIX 混用或使用多资产模型时，需要产品的 `default_index`。

## 新模型与敏感度

`CorrelatedBlackScholes(indices, spots, vols, divs, rate, correlations)` 验证指数唯一、矩阵对称/单位对角/正定，再以 Cholesky 关联每一步的因子。随机数按 step-major 排列，bridge 按因子执行。参数标签为 `spot:EQ[A]`、`vol:EQ[A]`、`div:EQ[A]` 等，以及共享 `rate`；相关系数是静态输入，不输出相关性风险。

`LocalVol` 对 log-spot 和时间作双线性插值，范围外平坦外推。每个产品时间间隔按 `max_step` 等分，用 checkpointed log-Euler scan 模拟；这对应 DAL 的平坦利率 HybridLocalVolEquity 组件。曲面替代输入 BS 的 scalar vol。标签包括 `spot:EQ[A]`、`div:EQ[A]`、`lvol:EQ[A]:i:j`、`rate:USD`；`model.vol_grid(grads["model"])` 返回按 spot 行、time 列排列的全部 bucket vega。

曲面时间轴使用与节点值相同的 dtype，保证 float32 Euler carry 不被提升为 float64。小曲面轴使用 `searchsorted(method="compare_all")`。JAX 0.11.2 在 GPU 上将默认二分查找 scan 嵌入 rematerialized Euler/AAD scan 后会触发 HLO evaluator 错误；此实现避免该嵌套，CPU/GPU 的价格和全部风险仍按原容差校验。

## 原生 oracle 与验证

PyPI 的 dal-python 2026.9.25 缺少部分 P5 功能。源码版仍使用相同版本号，因此测试通过能力检查识别它。CI 以固定提交 `4feabe89b105e0a3883fd4e2d74a2d70d618d8c7` 构建 DAL 的 C++ 和 Python 包。复现命令见 [examples/README.md](../examples/README.md)；使用目标环境的 Python 直接运行测试，避免 `uv sync` 将 oracle 换回 PyPI 包。

```bash
/tmp/dal-jax-native/bin/python -m pytest
# GPU 环境先安装 dal-jax[cuda13]，再安装同一 oracle：
XLA_PYTHON_CLIENT_MEM_FRACTION=.35 /tmp/dal-jax-native/bin/python -m pytest tests/gpu --run-gpu
```

本机完整源码 oracle CPU 回归基线：728 passed、37 skipped（GPU 默认关闭），285.26 s；实际 CUDA 13 GPU 基线：37 passed，108.24 s。随后补查 float32，修复插值时间轴引起的 Euler carry 类型提升，追加 2 个 CPU 用例和 5 个实际 GPU 用例，全部通过。延迟支付的不同日期归一化为同一事件模板，同时保留贴现槽位编号；另外通过 2 个 CPU scan/展开用例、4 个原生对照和 2 个实际 GPU 用例。PyPI oracle 套件先通过 690 项，后新增 3 个接口用例和 1 个容量调优用例均通过；最终改动另通过 104 项定向回归。12 个脚本均通过 CI 参数，09–12 另以默认参数在 CPU 和实际 GPU 上运行并保存报告。Lizard（CCN ≤8）、Pylint 错误级别、Bandit、Semgrep（151 条规则）均无发现。

价格相对容差为 1e-10，Greeks 为 1e-8，近零值绝对容差为 1e-10。对照涵盖 bridge 开关、exact/fuzzy、非整块路径数、历史参数风险、当日定盘策略、延迟付款、basket/worst-of、平坦/非平坦曲面和所有曲面节点风险。CPU 另外覆盖四种并行策略、确定性归约、scan/展开/checkpoint、jacfwd/jacrev/Hessian/vmap；局部波动率的全部参数和曲面节点通过共同路径有限差分。

DAL 源码 oracle 在 `FOR(i,0,3) APPEND(v,SPOT()+i) END v[5]=2 pay PAYS AVERAGE(v)+MAX(v)+MIN(v)` 的 AAD 调用中会发生段错误，独立的无 JAX 进程也可复现。09 使用没有空洞的 indexed write 作原生对照；JAX 的补零、最值梯度和空向量行为由独立测试验证。没有修改 DAL 源码或放宽数值容差。
